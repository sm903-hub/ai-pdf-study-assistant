# AI PDF Study Assistant

A student project exploring an AI assistant for studying from PDF notes.

## Planned features
- PDF text extraction
- Semantic search
- Question answering using a local Ollama model
- Answers with document page references

## Planned technology
Python, Streamlit, PyMuPDF, Sentence Transformers, FAISS, and Ollama.

## Project status
The current version is a static HTML landing page. The interactive AI application is planned separately.
